# Ennote go-to-market playbook

Ennote is a managed secrets platform for team credentials and Kubernetes workloads. Its agent pushes changes into native Kubernetes Secrets and can request rolling restarts for annotated workloads. The first sales conversation is about the gap between changing a credential and knowing the running app has picked it up.
